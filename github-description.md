# GitHub Description

Short description under 160 characters:

Local-first recurring charge audit desk that detects subscriptions, price creep, renewals, and cancellation priorities from statement exports.

Long description:

Subscription Leak Radar helps consumers audit recurring charges without connecting a bank account. It imports CSV exports or pasted statement text, detects repeated merchants and billing cadence, estimates annualized spend, flags price increases and duplicate categories, and exports a local Markdown/JSON cancellation priority report.

Alternative descriptions:

1. Find forgotten subscriptions and renewal leaks from local bank or card statement exports.
2. A private recurring charge radar for subscription audits, duplicate services, and what-if savings.
3. Turn messy transaction exports into a subscription renewal timeline and cancellation priority queue.
